# Circular Resource Intelligence Platform — Mentor Corrections

This deployment-ready static prototype includes:
- Login/sign-up gate before Action Center use (browser-local prototype account)
- English / Hindi / Marathi core interface support
- Consistent home-page generation metrics, including five-year average e-waste generation
- GIS status/error handling and more reliable map resizing
- Direct phone/email/source links for matched resource users, recyclers, aggregators and procurement contacts
- Updated agriculture contacts from SAMARTH/NTPC/Nabha public procurement/vendor sources
- Updated e-waste contacts from official Attero, Ecoreco and Namo public contact pages

Important: contact records are decision-support contact routes, not guaranteed purchase offers. Users must confirm current acceptance, specifications, pricing and logistics directly.

## Deploy
Upload the contents of this folder to Netlify, or drag the folder into Netlify's manual deploy area.
